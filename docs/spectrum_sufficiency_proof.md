# Spectrum sufficiency at (1,1) and (2,1): a proof, and the problem it leaves

**Status:** theory. A complete (finite-check-backed) proof that the gradient
spectrum decides persistence at (τa,τp) = (1,1) and (2,1) on the 2×2 core, a
proof *schema* that works at every τa ≥ τp cell tested, and an exact relocation
of the open problem. Every finite check cited here is executed and asserted by
[`experiments/spectrum_sufficiency_certificate.py`](../experiments/spectrum_sufficiency_certificate.py);
the oracle (exhaustive enumeration) referees every claim.

Setting: 2×2 core, cells around the reentrant loop in order 0→1→3→2, states
0 (receptive), 1..τa (active), τa+1..S (passive), S = τa+τp, θ = 1. The
*signature* of a configuration is its sorted multiset of cyclic phase gaps
mod (S+1) around the loop. A cell **dwells** at time t if it is receptive at t
and still receptive at t+1 (its neighbours gave it nothing to fire on).

---

## Theorem 1 (certificate schema)

*Let L be any set of signatures such that*

- **ING-1 (closure):** the configuration set C_L = {c : sig(c) ∈ L} is
  forward-invariant, and
- **ING-2 (activity):** every c ∈ C_L has at least one active cell.

*Then every configuration in C_L persists.*

**Proof.** By ING-1 and induction, the entire forward trajectory of any
c ∈ C_L stays in C_L. By ING-2, the configuration at every time has an active
cell. In particular the trajectory's attractor cycle — which is reached in
finite time since the space is finite — consists of configurations with
activity, which is the definition of persistence. ∎

Adding

- **ING-3 (complement):** every configuration outside C_L dies,

makes L an exact characterisation: *c persists ⟺ sig(c) ∈ L*.

Theorem 1 is trivial; its value is that it reduces "spectrum decides
persistence" to three **finite, mechanical checks** per (τa,τp) — no reasoning
about infinite time, no trajectory analysis.

A distinction the checker makes exact: taking L = {uniformly-live classes},
**ING-1 and ING-2 pass at every cell in *both* regimes** — so Theorem 1 proves
that pure-live-class configurations persist even at τp > τa (e.g. the 8
configurations of (1,2)'s two live classes). What is regime-bound is
**exactness**: ING-3 holds at every τa ≥ τp cell tested and fails at every
τp > τa cell (the script asserts exactly this split). At τa ≥ τp the
certificate characterises persistence; at τp > τa it only *witnesses* a
persistent core, and live members of mixed classes fall outside it.

## Theorem 2 ((1,1))

*At (τa,τp) = (1,1): c persists ⟺ sig(c) ∈ L = {(0,1,1,1), (0,2,2,2)}.*

**Proof.** |C_L| = 24, twelve configurations per class. ING-1: the exhaustive
24-row step table (in the checker; also §"anatomy" printout) shows each class
maps into **itself** — every member of (0,1,1,1) steps to a configuration of
signature (0,1,1,1), likewise (0,2,2,2). ING-2: every listed member contains a
cell in state 1. Theorem 1 applies, so all 24 persist. ING-3: the remaining
57 configurations fall in classes (0,0,0,0), (0,0,1,2), (1,1,2,2); enumeration
shows every one reaches the all-zero fixed point. ∎

The two live classes are, physically, the clockwise and counter-clockwise
coherent rotating waves; each is a single orbit of the group generated by loop
rotation and global clock-shift (4 × 3 = 12, checked). **Caution:** the
clock-shift does *not* commute with the step map (state 0 is exceptional), so
the orbit structure is a bookkeeping aid, not an equivariance argument — this
tempting shortcut is wrong, and the checker asserts the non-commutation.

## Theorem 3 ((2,1))

*At (τa,τp) = (2,1): c persists ⟺ sig(c) ∈ L = {(0,0,2,2), (0,1,1,2),
(0,2,3,3), (1,1,1,1), (1,2,2,3), (2,2,2,2), (3,3,3,3)}, |C_L| = 180.*

**Proof.** Same schema. ING-1: the class-level successor table closes within
L — five classes map to themselves; (0,0,2,2) and (1,2,2,3) map into each
other's union. (This two-class exchange is real transient structure, not an
abstraction artifact.) ING-2: every one of the 180 members has an active cell
(checked). ING-3: the 76 remaining configurations, in classes (0,0,0,0),
(0,0,1,3), (1,1,3,3), all die (checked). ∎

## Where the regime boundary actually lives (P6)

The proof schema exposes something the automaton work only hinted at. Checked
at all 12 cells, **both regimes**:

- ING-1 for the live set — *the set of persistent configurations is
  forward-invariant* — holds **universally**. (Trivially true for any
  deterministic map, but the checker verifies the implementation.)
- ING-2 for the live set — *every persistent configuration has an active
  cell* — holds **universally**.
- **What fails at τp > τa is exactly ING-3 / signature-measurability**: the
  live set stops being a union of signature classes.

So the open problem is relocated, exactly:

> **Why is the basin boundary of the dead state a union of signature classes
> precisely when the active band covers the passive band?**

## The dwell laws (P4, P5): the raw material for the general proof

Two exact laws, exhaustive at all cells tested, both regimes:

- **P4 (death = simultaneous waiting).** A configuration persists **iff** its
  trajectory never contains a step with *two or more* simultaneously dwelling
  cells. One dweller is survivable — the (1,1) live wave dwells once per beat
  (its period is 4 = 3+1, the +1 being the dwell; the period law of
  `spectrum_mechanism_hunt.py`). Two dwellers are always fatal, and every
  death passes through them (the all-zero state has four).
- **P5 (signature kinematics).** The signature changes **only** via dwell:
  no dweller ⟹ signature invariant; a dwell at loop position k shifts only
  the two adjacent gaps (upstream +1, downstream −1, mod S+1). So a live
  trajectory's signature performs single adjacent-gap exchanges — a discrete
  current on the gap multiset — and by P4 that is the *only* signature motion
  live trajectories exhibit.

Combining P4 and P6, the general conjecture becomes concrete and checkable
per cell:

> **Conjecture.** For τa ≥ τp, "some forward trajectory step has ≥ 2
> simultaneous dwellers" is a property of the signature alone; for τp > τa it
> is not. Equivalently: with the active band at least as wide as the passive
> band, whether two cells will ever *wait together* is determined by the
> relative lags around the loop, never by absolute refractory depth.

The §10 mixed-class example shows the τp > τa failure mode in one line: at
(2,3), signature (0,3,4,5) contains (0,0,1,3) — has an active cell, wave
bridges — and (0,0,3,4) — all non-receptive cells passive, so both receptive
cells dwell immediately: double-dwell, death. Same lags, different absolute
depths, opposite fates. At τa ≥ τp the wide active band makes "same lags ⟹
same dwell future" — that is the thing left to prove in general.

## Honest scope

- Theorems 2–3 are complete proofs *given* the finite checks, which are
  machine-verified but 81- and 256-configuration enumerations — the theorems'
  content is the *schema*, not depth at these sizes.
- The schema proves sufficiency cell by cell; it does **not** yet prove the
  regime law (that ING-3 holds for *all* τa ≥ τp). That requires the
  conjecture above or an induction on τ.
- All statements are 2×2-core; 3×3 versions of ING-1..3 hold empirically
  (the 3×3 automaton results) but the hand proof has not been lifted.

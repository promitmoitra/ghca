Greenberg–Hastings · plastic timescales

A medium that learns its own timescale

A homogeneous excitable medium. Every cell has one adjustable parameter — τ, how long it stays refractory before it can fire again — and a local rule that tunes τ from the timing of the input it receives. No gradients, no backpropagation, no objective function. Move the drive period and the medium retunes itself. Then break the rule in three different ways and watch it fail.

What you are looking at

Each pixel is one cell of a Greenberg–Hastings excitable medium on a torus: it rests, fires when enough neighbours are firing, then sits refractory for τ steps before it can fire again. Colour is each cell's learned τ — blue is fast, orange is slow — and brightness is its current activity, so you see the waves and the learned parameter field at the same time. A sparse scatter of pacemaker cells is driven on the beat so that waves exist at all.

Every cell also senses a weak afferent pulse on the beat. It is subthreshold by construction: it carries timing but never fires a cell. That distinction turns out to be the whole story.

The rule

On each input event, a cell nudges its own τ toward the interval since the last one: τ ← τ + η · (Δt − τ). Purely local, reward-free, and it can move τ down as well as up. Everything below is the same rule with the same η, differing only in which inputs count as an event.

Three ways to break it

Learn from every input and τ stops tracking the drive. Once τ settles, the medium sustains its own reentrant waves at period ≈ τ, so each cell's input is generated by its neighbours at interval ≈ τ — the rule measures its own output and sits at a self-confirming fixed point. The network re-introduces self-reference even though the rule was written to avoid it.

Learn from the cell's own firing and τ ratchets to the ceiling. Once τ overshoots the period the cell is still refractory when the next pulse arrives, so it skips one and measures a multiple of the true period — which pushes τ higher still. This is a one-way ratchet, and no fast population can ever form.

The working rule needs a channel it can attribute to the outside world. Given one, it tracks exactly and retunes in both directions.

Honest scope. Two things this demo does not show. Driving with two different periods at once does not produce fast and slow spatial domains: the fastest pacemaker entrains the whole medium, which is the standard excitable-media result and not something the rule can undo. And the afferent pulse here is global — every cell receives it, which means every cell is effectively in the sensory layer and the recurrence is not doing the learning. With the afferent confined to a localised sensory strip instead, τ does not lock anywhere in the medium: a distance gradient appears (error 1.5 near the strip rising to 2.9 far away) but never reaches the drive period, because several wavefronts arrive per cycle and a last-interval estimator cannot recover the rhythm. Whether a cell could discover which of its inputs is exogenous, rather than being told by architecture, is open; gating on low local activity does not do it.
